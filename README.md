# Mandarin Quest starter structure

Add these folders to the existing Mandarin Quest website repository.

- `teacher/index.html` — teacher dashboard
- `teacher/classroom.html` — 25-minute classroom companion, Unit 1 Lessons 1–9
- `assets/` — reserved for shared CSS/JS/media as the site grows

Recommended public path after deployment:
- `/teacher/`
- `/teacher/classroom.html`
